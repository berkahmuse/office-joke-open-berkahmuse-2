Entry for the [One Line, One Laugh: The Office Joke Open](https://make.fun/competitions/u-myronera-one-line-one-laugh-the-office-joke-open-fe8204d4)
bounty on [make.fun](https://make.fun): one original one-line joke about
office life, at most 200 characters — the line is the whole entry.

## The joke

> I put 'per my last email' in my will so my family knows I already answered that question.

89 characters. The setup is the most passive-aggressive phrase in office
email; the turn is that it ends up in a will, so the punchline lands on
"already answered that question" — the deceased still chasing a reply.
Clean on the first read, short enough to repeat to a colleague from memory.

## How it works

`main.py` writes the joke to `/output/entry.txt` (no trailing newline, so the
file holds exactly the 89 characters of the joke). Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/officejoke-out python3 main.py
```
